# Sudoku

Ein einfaches Sudoku als Web-App (PWA) fürs iPad. Reines HTML/CSS/JS, kein Build-Schritt.

**Installieren:** Die GitHub-Pages-Adresse in Safari öffnen, dann „Teilen → Zum Home-Bildschirm“. Danach läuft die App eigenständig und offline.

**Updates:** Nach Änderungen `VERSION` in `sw.js` erhöhen, damit das iPad die neuen Dateien lädt.
